# Little Studio

A responsive creative-studio landing page built with React and React-Bootstrap.
It includes a navigation bar, a hero heading, three project cards, and a contact
call to action.

## Run the app

From this directory, install dependencies and start the development server:

```sh
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

Create an optimized production build with:

```sh
npm run build
```

React-Bootstrap components are imported individually in `src/App.js`, and the
Bootstrap stylesheet is imported in `src/index.js`.
